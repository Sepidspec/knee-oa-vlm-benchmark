# Citation and thesis code availability

Use the repository's **Cite this repository** control, which reads
`CITATION.cff`. Include a fixed release tag or commit in the submitted thesis
so later edits do not change what the citation refers to.

Suggested reference, once version 1.0.0 is published:

> Azadian, S. (2026). *Knee OA Grading: Compact Vision–Language Model versus
> ResNet-18* (Version 1.0.0) [Computer software]. GitHub.
> https://github.com/Sepidspec/knee-oa-vlm-benchmark

Suggested availability statement:

> The study code, frozen experimental metadata, recorded predictions and
> analysis outputs are available at
> https://github.com/Sepidspec/knee-oa-vlm-benchmark. The repository provides
> the full Kaggle publication notebook and CPU utilities for verifying and
> regenerating the analyses. The original radiographs and trained weight
> files are not redistributed. The thesis uses the repository revision
> identified in its code citation.

Add the actual release tag or complete commit identifier to the final
reference. Do not cite the Kaggle temporary Jupyter proxy download URL: it is
session-dependent. A repository URL is not a DOI. An optional later Zenodo
archive can supply a DOI after GitHub integration and release archiving;
do not add a DOI until it actually exists.

The dataset, base model and relevant method papers require their own thesis
references. Citing this code repository does not replace those citations.
